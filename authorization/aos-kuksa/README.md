# Aos-to-KUKSA Authorization Adapter

This directory is reserved for the platform-owned Authorization Adapter
planned for AOS-5. No adapter or credential behavior is implemented here yet.

The future component will map authenticated Aos service identity and declared
resources to least-privilege KUKSA permissions. Temporary prototype tokens are
not an implementation of this boundary and must not be committed.
