# CARLA VISS-to-KUKSA Provider

This directory is reserved for the development-only provider planned for
AOS-2. No provider behavior is implemented in the R-2 scaffold.

Production platform profiles must be able to exclude this component
completely. Its eventual output must conform to the published vehicle
telemetry profile and must not expose CARLA-specific signals to services.
